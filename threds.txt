## Blueprint — Claude Sonnet sebagai Content Engine

---

## Overview

System ini generate konten harian untuk 10 persona affiliate Threads.
User pilih persona + jenis konten → Claude Sonnet balik caption siap posting + hashtag + hook.

---

## Stack yang Direkomendasikan

- Frontend: React / Next.js (atau HTML biasa juga bisa)
- AI Engine: Claude Sonnet via Anthropic API (/v1/messages)
- Storage: localStorage (simpan API key & history) atau Supabase kalau mau persist
- Deploy: Vercel / Netlify

## System Prompt Template

Ini yang lo kirim ke Claude sebagai system:

Kamu adalah {persona.name} — {persona.tagline}.

TENTANG PERSONA INI:
- Niche: {persona.niche}
- Tone: {persona.tone}
- Contoh suara khas: "{persona.voice_example}"
- Produk yang biasa direkomendasikan: {persona.products.join(", ")}
- Yang harus dihindari: {persona.avoid}

TUGASMU:
Generate konten Threads untuk persona ini. Threads mirip Twitter — 
maksimal 500 karakter per post, bisa multi-thread.

OUTPUT FORMAT (wajib JSON):
{
  "hook": "Kalimat pembuka yang bikin orang berhenti scroll (1 kalimat)",
  "caption": "Isi konten lengkap, natural sesuai persona (max 400 karakter)",
  "cta": "Call to action ringan, tidak hard sell (1 kalimat)",
  "hashtags": ["3-5 hashtag relevan"],
  "content_type_used": "tips/review/relatable/cta",
  "product_category": "Kategori produk yang disebut/diimply",
  "posting_tip": "1 tips singkat cara posting konten ini biar performanya bagus"
}

Jangan keluar dari persona. Jangan pakai bahasa formal atau bahasa iklan.
Respond HANYA dengan JSON valid. Tidak ada teks lain.

## API Call (contoh fetch)

js
async function generateContent(persona, contentType, userInput, apiKey) {
  const systemPrompt = buildSystemPrompt(persona);
  const userPrompt = buildUserPrompt(contentType, userInput);

  const res = await fetch("https://api.anthropic.com/v1/messages", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "x-api-key": apiKey,
      "anthropic-version": "2023-06-01"
    },
    body: JSON.stringify({
      model: "claude-sonnet-4-20250514",
      max_tokens: 600,
      system: systemPrompt,
      messages: [{ role: "user", content: userPrompt }]
    })
  });

  const data = await res.json();
  const raw = data.content[0].text;

  // Strip backticks kalau ada
  const clean = raw.replace(/
  return JSON.parse(clean);
}

## Catatan Penting

- Jangan hardcode API key di frontend. Kalau production, route lewat backend/server action.
- Response Claude kadang bungkus JSON dalam  ``json
- Kalau user gak isi topik, biarkan Claude bebas milih dari niche persona — hasilnya lebih natural.
- Komposisi konten (40/30/20/10) bisa dijadikan logic auto-select jenis konten biar feed-nya seimbang.
